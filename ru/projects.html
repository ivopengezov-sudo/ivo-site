PaletPlaner

Раскладка деталей из металла разной формы и толщины на паллеты для транспортировки решалась на глаз — часто с потерей места. PaletPlaner читает реальную форму деталей из загруженных DXF-файлов и автоматически рассчитывает оптимальную раскладку по нескольким паллетам, соблюдая реальные лимиты веса и высоты штабелирования. Спроектирован и разработан полностью самостоятельно, используется в реальной ежедневной работе — сейчас расширяется как инструмент по подписке для других цехов.

Время обработки — CNC калькулятор

Оценка времени обработки по техническому чертежу обычно требует экспертного расчёта "на глаз" — легко ошибиться на деталях с сочетанием сверления, фрезеровки и резьбы. Инструмент читает PDF чертёж через AI — распознаёт отверстия, резьбы, контуры и допуски — и передаёт данные напрямую в калькулятор, который считает реальное машинное время по инструментам, материалам и станкам конкретного цеха, а не по общим значениям. Полностью двуязычный интерфейс (болгарский/английский).

Каменна Стряха — демо-сайт гостевого дома

У небольших семейных гостевых домов часто нет собственного сайта, и они полагаются только на объявление на Booking.com — без рассказа о месте, номерах и кухне, который убедил бы посетителя забронировать напрямую. Демо-сайт гостевого дома в Родопских горах (построен в 1912 г., три номера, родопская кухня) — с описанием номеров, выбором дат для запроса на бронирование и локацией. Создан, чтобы показать, как выглядит профессиональное присутствие в сети для небольшого семейного бизнеса в туризме.

Плагин скидок для WooCommerce

Ручное создание и обновление промокодов для скидок легко забыть или сделать с ошибкой. Этот плагин полностью убирает этот шаг — как только сумма корзины превышает заданный порог, скидка 10% применяется автоматически как комиссия в корзине, без промокода. Построен на реальном хуке WooCommerce (woocommerce_cart_calculate_fees) и протестирован на действующем магазине WooCommerce.

Плагин отзывов для WordPress

Отзывы клиентов, разбросанные по письмам, скриншотам и обычному плагину контактной формы, трудно организовать и ещё труднее показать единообразно. Этот плагин даёт отзывам собственный структурированный тип контента — имя автора, роль и рейтинг в звёздах — отображаемый через простой shortcode в адаптивной сетке, плюс REST endpoint для получения тех же данных в headless-фронтенде.

Laravel система бронирования

Демо Laravel системы бронирования и оплаты: клиенты выбирают услугу и свободное время, оплачивают через Stripe Checkout, а webhook подтверждает бронирование после успешной оплаты. Двойное бронирование предотвращается реальной SQL-проверкой на пересечение, а панель администратора показывает и управляет всеми бронированиями.

Laravel клиентский портал

Laravel портал для подачи и просмотра документов: клиенты подают проект с сопроводительными файлами, сотрудники просматривают его и проводят через рабочий процесс по статусам, а готовые файлы возвращаются через тот же портал. Файлы хранятся на приватном диске — каждая загрузка проходит проверку прав доступа, никогда не раздаётся по угадываемому URL.
